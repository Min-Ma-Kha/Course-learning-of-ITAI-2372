# ShelfMic: Report

I chose a hosted LLM, Google's Gemini API (Option A, hosted inference, in the 2026 version of the assignment, using Gemini instead of OpenAI). The app calls it with plain `requests` behind a small provider layer, so a local Ollama model can be swapped in with one setting. My laptop is a Snapdragon X Elite (Windows on ARM), where Ollama runs on the CPU only, and I already had a Gemini key from an earlier assignment. I did not use the original aid's options because `text-davinci-003` and the old Completions API are retired, and GPT-2 is not instruction-tuned, so it continues text instead of following a writing brief. The biggest challenge was speed: the default `gemini-flash-latest` model "thinks" before answering and was too slow for an interactive app, so I switched to `gemini-flash-lite-latest`, which returned a clean description in about 2–3 seconds. Around the model I built two programmable layers. Rules map the audience to a customer segment and the sales channel to a length and format, and the page shows these choices as a decision trace. A rule-based claim checker flags unsupported claims, invented numbers and hype, then asks the model for one rewrite. In my experiments (tone with the facts held constant, plus a claim trap), all three tones used 5 of 5 facts, but tone changed length and risk. Formal copy was the shortest (80 words, below the 90–150 target), and humorous was the only draft the checker flagged, for "best", which the rewrite removed (7.5 seconds instead of about 2, because it took two calls). In the claim trap, the model kept "water-resistant" and never upgraded it to "waterproof." Reading the outputs myself also showed the checker's limits. The formal copy claimed "traction across varied terrain" and comfort "over long distances," and the casual copy mentioned "longer excursions," even though the facts only said "designed for day hikes"; none of these phrases are on the checker's list. The checker also marked "machine washable" as unused when the model wrote "tossing it in the washing machine," so its keyword check is stricter than a person would be.

This connects directly to AI in retail. Marketplaces and e-commerce platforms already generate listings from seller attributes and personalize copy by customer segment and channel, and a "not as described" item is one of the most common reasons for returns, which costs retailers shipping, handling and resale value. Improvements beyond the stretch goal would be to pull facts from a trusted product catalog instead of free text, require human approval before publishing, A/B test descriptions against real conversion and return rates, add multilingual output, and compare Gemini with a local model on quality, speed, cost and privacy. The main ethical risk is misleading advertising: my own results show the model can overreach with confident, plausible phrases that a keyword list does not catch, so a person must stay accountable for every published claim. Audience rules can also turn into stereotypes, and tone matters for respect; the humorous version joked that the shopper doesn't know what they are doing, which some customers could find off-putting. Finally, anything sent to a hosted API leaves the business, so real customer or unreleased product data needs a privacy review first.
